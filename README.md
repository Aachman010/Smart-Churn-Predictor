# Smart Customer Churn Predictor

An end-to-end Machine Learning web application that predicts telecom customer churn probability in real time.

## Tech Stack
- **Machine Learning:** Python, Pandas, Scikit-Learn (`ColumnTransformer`, `Pipeline`), XGBoost (`scale_pos_weight` for class imbalance)
- **Backend:** FastAPI, Pydantic, Uvicorn, Joblib
- **Frontend:** HTML5, CSS3, JavaScript
